# Mailcow — Mail Server

Mailcow runs as a **separate Docker Compose stack** at `/opt/mailcow` on the VPS.
It connects to the existing `hashcode-public` network so Traefik handles HTTPS for the web UI.

## Initial Setup (VPS)

```bash
cd ~/hashcode-infra
sudo bash mailcow/setup.sh
sudo bash mailcow/start.sh
```

## DNS Records

Configure these DNS records before starting:

| Type   | Name                              | Value                                                          |
|--------|-----------------------------------|----------------------------------------------------------------|
| A      | `mail.hashcode.digital`           | `<VPS_IP>`                                                     |
| MX     | `hashcode.digital`                | `mail.hashcode.digital` (priority 10)                          |
| TXT    | `hashcode.digital`                | `v=spf1 mx a -all`                                             |
| TXT    | `dkim._domainkey.hashcode.digital`| *(copy from Mailcow admin > Configuration > ARC/DKIM keys)*    |
| TXT    | `_dmarc.hashcode.digital`         | `v=DMARC1; p=quarantine; rua=mailto:postmaster@hashcode.digital` |
| CNAME  | `autoconfig.hashcode.digital`     | `mail.hashcode.digital`                                        |
| CNAME  | `autodiscover.hashcode.digital`   | `mail.hashcode.digital`                                        |
| PTR    | `<VPS_IP>`                        | `mail.hashcode.digital` *(set via hosting provider)*           |

## Firewall Ports

Open these ports on the VPS in addition to 80/443 (already open):

| Port | Protocol | Service    |
|------|----------|------------|
| 25   | TCP      | SMTP       |
| 465  | TCP      | SMTPS      |
| 587  | TCP      | Submission |
| 143  | TCP      | IMAP       |
| 993  | TCP      | IMAPS      |
| 110  | TCP      | POP3       |
| 995  | TCP      | POP3S      |

## Updating Mailcow

```bash
sudo bash ~/hashcode-infra/mailcow/update.sh
```

This runs Mailcow's upstream `update.sh`, then re-applies the override.

## Folder Structure

```
/opt/mailcow/                        # Mailcow upstream (git clone)
├── docker-compose.yml               # Upstream (DO NOT EDIT)
├── docker-compose.override.yml      # Copied from hashcode-infra/mailcow/
├── mailcow.conf                     # Generated by setup.sh
└── ...                              # Other upstream files

~/hashcode-infra/mailcow/            # Our customizations (this directory)
├── docker-compose.override.yml      # Traefik integration override
├── setup.sh                         # One-time setup script
├── start.sh                         # Start helper
├── update.sh                        # Safe update helper
└── README.md                        # This file
```

## Local Development

For local dev, `mailpit` is included in the main `docker-compose.override.yml`.
Access the mail UI at `http://mail.localhost` and send test emails to SMTP port `1025`.
